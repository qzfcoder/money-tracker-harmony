# 一页账

基于 HarmonyOS NEXT Stage 模型的纯本地轻量记账应用骨架，产品方向参考钱迹：不开账号、不接广告、不上传账单数据。

## 当前已落地

- Stage 入口与主路由配置
- 4 个底部 Tab：首页、统计、资产、我的
- 记账页、关于页等二级页面占位
- MVVM 分层目录：model、database、repository、viewmodel
- RDB 建表 SQL：账单、分类、账户、预算
- 默认支出/收入分类与默认账户数据
- 首页月度概览、流水样式、快速记账入口
- 统计页：周/月/季/年/自定义区间切换，区间收支汇总、分类占比、趋势图、柱状对比

## 下一步建议

1. 在 DevEco Studio 中导入工程并同步 SDK 配置。
2. 先联调 `AppDatabase.init()` 与首页真实数据加载。
3. 完成 `RecordEdit` 的编辑模式、删除确认和详情页跳转。
4. 继续补数据导出备份、分类管理和账户管理。
