# 一页账

基于 HarmonyOS NEXT Stage 模型的纯本地轻量记账应用：不开账号、不接广告、不上传账单数据。

## 当前已落地

- 4 个底部 Tab：明细、统计、资产、我的
- 手动记账、账单编辑、账单详情和删除
- 分类管理、账户管理、预算管理
- 收支日历、搜索筛选、区间收支汇总
- 统计页：周/月/季/年/自定义区间切换，分类占比、趋势图、柱状对比
- 数据导出：本月账单或最近 1000 条流水 CSV，支持统计 PDF
- JSON 数据备份恢复、本应用 CSV 导入和重复记录跳过
- 转账录入，支持转出账户和转入账户
- 浅色、深色和跟随系统外观设置
- 发布版不申请敏感权限，不展示隐私弹窗、通知、短信、后台截图或主动识别入口

## 实验功能

- 闪控球主动触发识别流程，默认关闭，说明见 `docs/auto-bookkeeping-floating-ball.md`

## 下一步建议

1. 在 DevEco Studio 中导入工程并同步 SDK 配置。
2. 运行 `powershell -ExecutionPolicy Bypass -File tools\release-check.ps1` 做发版检查。
3. 在真机或模拟器完成记账、资产、预算、搜索、导出主流程回归。
4. 用 DevEco Studio 执行正式构建与签名。
